# Gimdow Smart Lock for Home Assistant

Home Assistant custom integration for the **Gimdow Smart Lock** using the Tuya OpenAPI.

## Requirements
- A [Tuya IoT Developer](https://developer.tuya.com/) account.
- A Cloud Project in the Tuya IoT Platform with the "Smart Home Scene Linkage" API authorized.
